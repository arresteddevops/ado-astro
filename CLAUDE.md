# Arrested DevOps — Astro site

Astro rebuild of https://www.arresteddevops.com (a podcast website), deployed on Netlify.
Port of the Hugo site in `../ado-hugo` (github.com/arresteddevops/ado-hugo, castanet theme).

## Current state

Planning complete; build not started. Read before writing code:
- `docs/PRD.md` — 13 locked decisions, phases (= GitHub issues 1–8), success criteria
- `docs/adr/` — feed rebuild, person-centric guest model, content source of truth
- `CONTEXT.md` — the glossary; use its terms (Guest, Bio Snapshot, Alias, The Feed)
- Design: Broadcast Pop canvas, linked in the PRD (About page copy is draft)

## Reference: the legacy site (`../ado-hugo`)

- `content/episode/` — 205 episodes, TOML frontmatter: `podcast_file`, `podcast_duration`,
  `podcast_bytes`, `episode` (number), `guests`/`hosts`/`sponsors` (refs by filename),
  `episode_image`, `episode_banner`, `images` (social), `aliases` (short URLs like `/205`),
  `transcript`, `explicit`, `youtube`, `upcoming`
- `content/guest/` — 332 guest profiles; `content/host/`, `content/sponsor/`,
  `content/page/`, `content/redirect/` (vanity-URL stubs)
- `data/hosts/`, `data/sponsors/` — supplemental data files
- `layouts/shortcodes/` — `bloglink`, `booklink`, `podcast`, `staticsearch` (used inside
  episode markdown; the port must handle these)

## Hard constraints

- **URLs must not break.** Permalinks are flat (`/:filename/`), plus per-episode aliases
  (`/205` etc.) and the `content/redirect/` vanity URLs.
- **The podcast RSS feed is load-bearing.** Podcast apps subscribe to the feed generated by
  the site. Any change to feed URL or shape needs an explicit decision (ADR), not an accident.
- Deploys on Netlify; `netlify.toml` is the build source of truth.
